# Lint configuration notes

`react/no-unescaped-entities` is **off**. It flags a bare `'` in JSX text —
`don't`, `you're`, `let's`. React renders those correctly; the rule exists to
catch a narrow class of typo, and this codebase's marketing and tool pages are
written in plain English, so it fired 72 times without finding a single real
problem. Leaving it on would have buried the rules that do find things.

`react-hooks/exhaustive-deps` stays on (as a warning, the Next.js default).
Every current warning is the same deliberate pattern:

```tsx
async function load() { ... }
useEffect(() => { load(); }, [hid]);
```

`load` is redeclared each render, so adding it to the dependency array would
refetch in a loop. The idiomatic fixes are `useCallback` or a ref. That's a
real cleanup worth doing — but it touches ~18 components across the dashboard,
so it belongs in its own change rather than in a launch prep pass. The warnings
are left visible on purpose so the work doesn't get forgotten.
